# sound-reactive-tree
An interactive web project where a fractal tree grows based on microphone sound input. Speak or clap to see branches, leaves, and fruits dynamically appear. Built using p5.js and JavaScript.
## Working
Speak or clap to make branches, leaves, and fruits appear, then watch it smoothly decay when sound stops.
## How to Run
Open index.html in your browser
OR open your GitHub Pages link
## How to Use
Click Start Microphone  
Allow microphone permission  
Speak or clap  
The tree will grow with sound  
Click Reset to restart
## Technologies Used
HTML
CSS
JavaScript
p5.js
p5.sound
## Note
Microphone must be allowed in browser
Close apps like Zoom/Teams if mic is not working
Works best in Chrome
